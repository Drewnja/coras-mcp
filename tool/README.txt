 INSTALLATION
==============
Unpack the zip file containing the CORAS diagram editor in a
suitable location.  This will create a directory named
'diagram-editor-2.0b1'.

To use the CORAS diagram editor, you also need the Java SE 5 runtime
environment (JRE) or development kit (JDK), which can be downloaded
from http://java.sun.com/javase/downloads/


 USAGE
=======
In windows, you can double-click the diagram-editor-2.0b1.jar file
located in the installation directory to run the diagram editor.
It can also be run with the command

  java -jar diagram-editor-2.0b1.jar
